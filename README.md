# Skillpath

React/TypeScript Code Component for the Skillpath course section, built for the Webveda junior developer assignment.

## Features

- Fetches live course and country data from the provided API
- Displays INR or USD pricing based on country
- Handles loading, error, and empty states
- Handles country API failure without hiding successfully loaded courses
- Retry support
- Search and price sorting
- Refundable course filtering
- Responsive 3/2/1 column layout
- Skeleton loading state

## Framer Property Controls

The component exposes two designer-configurable controls:

- `Title`
- `Card Accent`

## File

`CourseComponent.tsx` contains the complete Framer Code Component implementation.
